# ray-doris 1.2

## Highlights

- Add Python 3.11 / Ray 2.58.0 to the tested compatibility matrix, including unit and public
  contract tests, base and Flight wheel installation, dependency checks, and import tests.
- Check installed dependencies for the Python 3.12 wheel and source distribution smoke tests.
- Validate that the README and compatibility documentation match the CI Python / Ray matrix.
- Remove the project-wide Alpha classifier and current maturity label without assigning a Beta or
  Stable classifier.
- Rename the default release evidence profile from `alpha` to `standard` while preserving its
  existing validation requirements.

## Compatibility and release scope

- Keep the package version format at two components: `major.minor`.
- Keep the existing Python, Ray, and Doris compatibility bounds and read/write contracts.
- Retain Python 3.9 as a legacy compatibility target outside the production profile.
- Keep MySQL as the production-candidate read transport. Flight SQL, automatic transport selection,
  and deployment-specific Flight TLS remain experimental.
- Required real-Doris integration tests continue to use Python 3.12 and Doris 4.0.6. Python 3.11
  coverage does not add a separate real-Doris deployment certification.
- The standard release profile validates CI, package artifacts, and installation smoke tests. It
  may defer exact-candidate full distributed evidence and makes no stable or enterprise distributed
  certification claim. The enterprise profile continues to require that evidence.
- Write task retries remain disabled. Stream Load requests do not provide whole-Dataset atomicity
  or exactly-once semantics.
