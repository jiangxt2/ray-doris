# ray-doris 1.3

## Highlights

- Extend the supported Ray Data window through final Ray 2.59 releases.
- Add Ray 2.59.0 unit, public-contract, package, and real Doris 4.0.6 validation.
- Align the optional full distributed suite with Ray 2.59.0.

## Compatibility

- Final Ray releases `>=2.49.2,<2.60`.
- Ray 2.59.0 is verified on Python 3.11, 3.12, and 3.13; the full required Doris
  integration profile uses Python 3.12.
- Apache Doris 4.0.6 remains the fixed real-service target.
- The standard release profile retains its documented evidence scope. The enterprise
  profile continues to require a successful full distributed manifest for the exact
  candidate commit.

## Validation

- The Ray 2.59.0 CI matrix, Python 3.11/3.12/3.13 unit and contract suites, package
  installation, and required Doris integration passed against this implementation.
- The Ray 2.59.0 full distributed functional suite passed locally with three Ray workers
  and three Doris backends.
- Wheel, source archive, Twine, and isolated installation checks passed.

## Scope

This release adds Ray 2.59.0 compatibility. It does not change read, write, retry,
transaction, or maturity guarantees.
