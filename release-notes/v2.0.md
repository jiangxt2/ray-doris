# ray-doris 2.0

## Highlights

- Add projection, supported predicate, and row-budget pushdown for table reads.
- Add experimental opt-in native reads for eligible Hive Parquet and Iceberg REST catalogs.
- Add trusted SQL query-result reads through one streaming MySQL task.
- Improve HDFS Kerberos support, failure classification, and safe diagnostics.

## Compatibility

- Python 3.11 or later and final Ray releases `>=2.57.0,<2.60` are required.
- Python 3.9 and 3.10 and Ray releases before 2.57 are no longer supported.
- Native external-table reads are opt-in and require the documented access and identity conditions.
- Query SQL is trusted input. Schema discovery or retries can execute the SQL again.

## Validation

- The Python/Ray matrix, package checks, and Doris 4.0.6 integration run in CI.
- The standard release profile does not claim exact-candidate full distributed validation.

## Scope

Native reads do not imply authorization equivalence across Doris, catalog, and storage
identities. Reads across tasks do not share a snapshot. Existing write and ambiguous-outcome
boundaries continue to apply.
